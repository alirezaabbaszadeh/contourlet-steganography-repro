\section*{Supplementary Note S2: Layer-integrity format and internal methods}
The version-2 internal format uses a 127-byte raw header encoded as one RS(255,127) codeword (255 encoded bytes; 2,040 bits). Reserved header capacity stores independent Base and Detail CRC32 fields in addition to complete-message integrity. At the 100\% operating point, the four most-significant bits of each 128$\times$128 secret pixel form Base and the four least-significant bits form Detail. A Base-only reconstruction is accepted only when all declared Base bytes and the Base CRC validate.

C0 uses fixed allocation, symmetric protection, and non-prioritized placement. C1 adds adaptive allocation. C2 uses unequal Base/Detail protection with fixed allocation. C3\_NP combines adaptive allocation and unequal protection while retaining alternating layer order. C3 shares allocation, protection, weights, quotas, ordered coefficient map, and map fingerprint with C3\_NP but changes transport order to Base first. This makes C3 versus C3\_NP the preregistered placement-priority comparison.

The progressive payload sweep transmits the most-significant information first: 25\% uses 2 Base bits/pixel and no Detail; 50\% uses 4 Base bits/pixel; 75\% uses 4 Base plus 2 Detail bits/pixel; and 100\% uses 4+4 bits/pixel. Omitted lower bitplanes are deterministically zero-filled during reconstruction. At lower fractions the unequal-protection methods carry more protected bits than symmetric methods, so nominal raw fraction and actual protected bits must both be reported.

\section*{Supplementary Note S3: Transform and engineering controls}
The internal transform profile is \code{octave\_pdfb\_9\_7\_pkva\_nlev\_2222\_p3p4\_range\_v2}. It uses 9--7 pyramid filters, PKVA directional filtering, four levels, and independently writable P3+P4 range coordinates. Transform identity, function resolution, reconstruction, capacity, writability, self-gain, cross-talk, off-target energy, and dense sign-recovery checks were frozen before production. Adaptive allocation is bound to calibration evidence through the transform fingerprint.

B1 is a harmonized grayscale $k$-LSB engineering control with frozen candidate set $k\in\{1,2,3,4\}$. B2 is a harmonized block-DCT scalar-QIM control using 8$\times$8 blocks, 32 frozen AC positions, exact full-payload capacity 131,072 raw bits, the frozen delta list \(\{2.5,2.75,3.0,3.1,3.25,3.5,3.75,4.0,4.5,5.0,6.0,8.0,10.0,12.0\}\), and at most four deterministic clean repair passes. Only clean-valid candidates are admissible. If the frozen candidate set cannot produce a valid clean embedding, the pair remains a scientific prerequisite failure; no additional parameter is introduced after outcome inspection.

\section*{Supplementary Note S5: Failure semantics and statistical analysis}
Scientific validity states are kept distinct from execution failures. Internal clean-decode failure or exhaustion of the frozen B2 clean-valid candidate set is a scientific prerequisite failure. Dependent channel cells are represented as \code{not\_evaluated}; unavailable numerical endpoints remain unavailable rather than being set to zero. Other missingness classes are \code{missing\_operational}, \code{not\_applicable}, and protocol violation.

The image pair is the primary analysis unit. Repeated random channel realizations are aggregated within pair--method--severity cells before primary inference. The preregistered comparison family is C3 versus C0, C3 versus C3\_NP, C3 versus B1, and C3 versus B2. Effect sizes are accompanied by 95\% pair-cluster bootstrap intervals using \FinalBootstrap{} repetitions and endpoint-appropriate paired tests with Holm adjustment. Numeric paired summaries use only pairs for which the endpoint is defined and report that paired count.
