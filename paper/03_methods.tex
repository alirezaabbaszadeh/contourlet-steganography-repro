\section{Methods}

\subsection{Self-describing and failure-aware decoding}

The RS(255,127)-protected header records the format and method identifiers, ECC layout, image dimensions, layer codeword counts, payload length, interleaver and scrambler identifiers, payload CRC32, and a SHA-256 digest of the canonical configuration. Base and Detail randomisation streams are derived separately from domain-separated material containing the master seed, pair identifier, method, layer, and purpose.

The receiver validates the header before decoding both layers. A secret image is produced only when the required Reed--Solomon decodes succeed and the complete payload CRC is valid. Failures retain the stage, layer, codeword index, and corrected-symbol counts. This separates raw bit damage and partial correction from valid complete recovery. Full framing and validation rules are given in Supplementary Note S1.

\subsection{Audited transform interpretation}

The final profile uses 9--7 pyramid filters, PKVA directional filtering, four multiscale levels, and independent P3+P4 range coordinates. The adapter verifies that required functions resolve inside the locked PDFB toolbox and records the toolbox, bridge, configuration, band inventory, and transform fingerprint. Reconstruction, capacity, writability, self-gain, cross-talk, and off-target-energy gates are described in Supplementary Note S2. This profile is an explicit independent interpretation, not the undisclosed configuration of the source authors.

Four fixed traceability pairs yield 16 embeddings. Mandatory evaluation includes clean output, JPEG quality 70, Gaussian variance 10, and salt-and-pepper density 0.03. Predeclared triggers activate hard checks at JPEG quality 50, Gaussian variance 15, and salt-and-pepper density 0.05, producing 64 mandatory and 24 conditional rows. Every method uses the same pair, payload, transform fingerprint, PSNR rule, and channel realisation.

Recorded outcomes include cover--stego quality, raw BER, Base and Detail BER, header and payload validity, valid-secret quality, selected strength, runtime, memory, and immutable object identifiers. The conservative primary measure is effective unrecovered bit rate, \(\eur\): zero denotes valid complete recovery and one denotes failure of the complete recovery contract. Statistical contrasts and their small-sample interpretation are detailed in Supplementary Note S4.

\subsection{Execution and provenance}

Each embedding and evaluation is a content-addressed object written atomically and reused only after schema and SHA-256 validation. Corrupt cache objects are quarantined. A runtime gate kills a real worker with SIGKILL, verifies unchanged completed objects, resumes unfinished work, and validates the exported archive. Supplementary Note S5 describes the runtime, monitoring separation, and evidence capsule.
