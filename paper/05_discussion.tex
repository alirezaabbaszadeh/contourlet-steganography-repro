\section{Discussion}

The most informative result was also the least convenient one. C3 gave Base more redundancy and earlier access to the highest-ranked coordinates, yet none of the attacked streams passed the final integrity check. That outcome does not cancel the coding gain; it shows where the gain stopped. In this experiment, stronger protection increased the design margin without changing the binary recovery outcome.

Several mechanisms can produce that pattern. The \SI{45}{dB} quality constraint limits coefficient displacement, while the 222,360-bit transport occupies a large coordinate pool. Complete validity also depends on the protected header and both layers, so one critical codeword can reject a stream that still contains substantial correct information. Unequal protection further trades Detail redundancy for Base redundancy. The medium settings may therefore sit beyond a relatively narrow transition region in which the extra Base protection would change complete recovery.

The negative result remains useful because the protocol was not rewritten after it appeared. We did not reduce the payload, relax PSNR, replace image pairs, or keep adding channel settings until one method won. The completed run establishes a clear boundary: the clean transport worked, the Base code structure became stronger, and the selected channels still overwhelmed every complete-payload configuration.

That boundary is unusually inspectable. Each row is linked to one pair, method, transform fingerprint, attack realisation, embedding object, and evaluation object. Future experiments can therefore test a new threshold or payload without silently replacing the history of this one.

\section{Limitations and Future Work}

The study contains four fixed traceability cases, so its inference is case-bounded. The PDFB profile is explicit but not author-equivalent, extraction is semi-blind, and geometric attacks and steganalysis lie outside the final factorial evidence. The strict complete-payload rule may also hide useful partial Base preservation.

The next experiment should preregister finer channel increments between clean operation and the failed medium settings. Header validity, Base and Detail codeword failures, corrected-symbol distributions, layer BER, Base-only integrity, payload CRC, and \(\eur\) should be plotted against severity. A separately validated Base CRC could then test whether unequal protection enables a lower-fidelity but still meaningful reconstruction when Detail is lost. Direct comparison with the source article should wait until the transform, payload, pairing, quantisation, extraction, attacks, and metrics have been harmonised.

\section{Conclusion}

This study turned an underspecified contourlet description into a controlled transport experiment. C3 demonstrably strengthened the Base layer, increasing its nominal correction budget by 51.2\% and prioritising it in the coordinate map. The tested JPEG, Gaussian, and salt-and-pepper channels nevertheless remained beyond complete recovery. The contribution is therefore not a claim of universal robustness. It is a clearer account of what was strengthened, where recovery failed, and how the same boundary can be checked again.
