\section{System Architecture}

A \(512\times512\) grayscale cover carries a \(128\times128\) grayscale secret. Inputs are constrained to uint8, and clipping plus half-up rounding define the digital boundary. The secret is split into four most-significant Base bits and four least-significant Detail bits per pixel. Each layer contains 8,192 raw bytes.

Base and Detail are independently coded, scrambled, and interleaved. A protected 127-byte header contributes 2,040 bits, and the complete fixed transport contains 222,360 bits. Embedding and extraction reconstruct the same deterministic slot plan from the cover, method, configuration, and calibration profile. Extraction is semi-blind because the original cover is used to measure coefficient differences.

\subsection{Hierarchical unequal protection}

C0 and C1 use symmetric protection. Each layer receives 32 RS(255,127) and 22 RS(255,191) codewords. C2 and C3 redistribute the same total number of codewords: Base receives 65 RS(255,127) blocks and Detail receives 43 RS(255,191) blocks. No additional transport capacity is created; redundancy is moved toward the more perceptually important layer.

For C0, the nominal Base correction budget is
\begin{equation}
32(64)+22(32)=2,752\ \text{symbols}.
\end{equation}
For C3, it is
\begin{equation}
65(64)=4,160\ \text{symbols},
\end{equation}
a 51.2\% increase, provided that no individual codeword exceeds its own correction radius. Boundary tests verify correction at 64 versus failure at 65 altered symbols for RS(255,127), and at 32 versus failure at 33 for RS(255,191).

\subsection{Transform-bound adaptive allocation}

Adaptive methods score each eligible band from four signals: coefficient energy, variance, entropy of absolute magnitudes, and calibration-derived channel stability. Robust median/MAD normalisation limits domination by outlying bands. Stability is estimated only from designated calibration covers exposed to JPEG, Gaussian, and salt-and-pepper perturbations; the resulting profile is accepted only when its transform fingerprint matches the active adapter.

Scores determine both integer band quotas and local embedding weights in the range 0.75--1.25. C1 uses this policy with symmetric coding. C2 uses unequal coding with fixed allocation. C3 combines both and uses a \method{base\_then\_detail\_high\_score\_first} layout, giving Base earlier access to higher-scoring coordinate groups.

\subsection{Capacity and quality controls}

The allocator selects exactly 222,360 unique coefficient slots without exceeding any band capacity. The complete map is deterministic and hashable. A binary search then selects the largest global embedding strength that remains feasible after inverse transformation, clipping, rounding, and uint8 conversion. All variants are therefore compared at the same realised cover--stego PSNR target of \SI{45.0\pm0.1}{dB} and the same payload size. Detailed allocation invariants, seed derivation, header layout, and coefficient-map auditing appear in Supplementary Notes S1--S3.
